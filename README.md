# AN LINKS

منصة ويب متقدمة ومفتوحة المصدر لإنشاء صفحات الروابط الشخصية (Link-in-Bio) باللغة العربية، مصممة للمبدعين وصنّاع المحتوى والأنشطة التجارية في العالم العربي مع دعم كامل لاتجاه القراءة من اليمين إلى اليسار (RTL) وأداء فائق السرعة.

---

## ✨ المميزات الرئيسية (Features)

- **دعم كامل للغة العربية (RTL-First):** خطوط عربية مدمجة (Cairo، Tajawal، IBM Plex Sans Arabic) وتنسيق متوافق مع كافة أحجام الشاشات.
- **عرض سريع وتصيير من الخادم (SSR):** زمن تحميل فوري للصفحات العامة على مسار `/{username}` مع توليد وسوم المشاركة وSEO (Open Graph).
- **لوحة تحكم ومعاينة مباشرة (0ms Live Preview):** محاكي جوال تفاعلي يعكس التغييرات في المظهر والروابط وشبكات التواصل فورياً دون إعادة تحميل.
- **تحويل آمن وذري للنقرات (`/go/[id]`):** تسجيل إحصاءات النقرات ذرياً في قاعدة البيانات مع استبعاد الزواحف الآلية (Bots & Social Crawlers) لحماية دقة الإرقام.
- **تتبع المشاهدات غير المتزامن:** تسجيل المشاهدات عبر Beacon API دون التأثير على سرعة التحميل.
- **تخصيص المظهر والقوالب:** 4 قوالب جاهزة (Minimal Clean, Dark Midnight, Emerald Garden, Warm Sunset) مع خيارات استدارة الحواف وأنماط الأزرار.
- **معالجة ورفع الصور الآمن:** حماية ضد قنابل إلغاء الضغط (Decompression Bombs)، وفحص أبعاد الصور، وحذف بيانات EXIF، والتحويل إلى صيغة WebP فائقة الخفة بمكتبة Sharp.
- **لوحة تحليلات تفاعلية:** رسوم بيانية لمشاهدات الصفحة والنقرات خلال 7 أو 30 يوماً مع حساب معدل النقر (CTR %).
- **نظام مكافحة الاحتيال والبلاغات:** نافذة إبلاغ للمتابعين على كل صفحة عامة وفحص عناوين URL ضد الروابط الخبيثة ومختصرات الروابط المزدوجة.

## 🛠 البنية التقنية (Tech Stack)

- **الإطار البرمجي:** Next.js 15+ (App Router, Server Components & Server Actions)
- **لغة البرمجة:** TypeScript
- **قاعدة البيانات:** PostgreSQL مع Prisma ORM
- **التصميم والواجهة:** Tailwind CSS & Lucide Icons
- **المصادقة:** Auth.js / NextAuth مع تشفير bcryptjs
- **معالجة الصور:** Sharp
- **الاختبارات:** Vitest (47 اختبار آلي ناجح يغطي كافة المكونات)

## 🚀 التشغيل والتطوير المحلي (Getting Started)

### المتطلبات المسبقة:
- Node.js v18+ (أو v20+)
- npm أو pnpm أو yarn
- خادم PostgreSQL

### خطوات التشغيل:

1. **تثبيت الاعتماديات:**
```bash
npm install
```

2. **تجهيز متغيرات البيئة:**
انسخ ملف `.env.example` إلى `.env` وقم بتعيين عنوان الاتصال بقاعدة البيانات ومفتاح التشفير:
```bash
cp .env.example .env
```

3. **توليد عميل Prisma:**
```bash
npx prisma generate
```

4. **تشغيل الاختبارات الآلية للتأكد من سلامة النظام:**
```bash
npm test
```

5. **بدء خادم التطوير المحلي:**
```bash
npm run dev
```

افتح المتصفح على:
- لوحة التحكم: `http://localhost:3000/dashboard`
- صفحة التسجيل: `http://localhost:3000/register`
- نموذج صفحة عامة: `http://localhost:3000/ammar`
