# خطة تنفيذ المعاينة الحية والتفاعلية فائقة الواقعية للهاتف الذكي
(Implementation Plan: Ultra-Realistic Interactive Phone Live Preview)

* **التاريخ:** 2026-11-24
* **الهدف:** بناء نظام معاينة حي وتفاعلي يمنح المستخدم إحساساً حقيقياً ومطابقاً بنسبة 100% لتجربة استخدام الهاتف الذكي، مع دعم النقر التفاعلي والـ Webview الحقيقي.

---

## المهام التنفيذية (Tasks Breakdown)

### المهمة 1: ترقية هيكل الهاتف الواقعي (`PhoneChassis.tsx`)
- إضافة دعم أنماط هياكل التيتانيوم الثلاثية (`titanium`, `obsidian`, `gold`).
- إضافة خطوط الهوائي الميكانيكية (Antenna Bands) وانعكاسات الزجاج المنحني (Glass Highlights).
- مؤشر الهوم التفاعلي (Home Indicator).
- خط الحد: $\le 100$ سطراً.

### المهمة 2: تطوير الجزيرة التفاعلية الحية وشريط الحالة (`PhoneDynamicIsland.tsx`)
- ساعة رقمية حية تظهر التوقيت الفعلي وتتحدث تلقائياً كل ثانية/دقيقة.
- جزيرة تفاعلية (Dynamic Island) قابلة للنقر والتوسيع التفاعلي لعرض حالة الاتصال والمنصة.
- أيقونات بطارية و Wi-Fi و 5G فائقة الدقة.
- خط الحد: $\le 120$ سطراً.

### المهمة 3: إنشاء شريط متصفح الهاتف المحاكي (`PhoneBrowserBar.tsx`)
- شريط Safari / Chrome مصغر وأنيق يحاكي واجهة المتصفح الحقيقي.
- عنوان الرابط الحقيقي: `🔒 anlinks.dev/{username}`.
- زر إعادة التحميل (Reload Preview) لتنشيط وتحديث المعاينة فوراً.
- زر نسخ الرابط ومشاركة الصفحة.
- خط الحد: $\le 110$ سطراً.

### المهمة 4: تحويل عناصر الروابط إلى روابط تفاعلية حقيقية (`PhoneInteractiveLink.tsx`)
- أزرار تفاعلية حقيقية تدعم النقر وتأثير التموج والضغط الفعلي.
- فتح نافذة فحص الرابط أو توجيه المستخدم بأمان.
- تفاعلية أيقونات التواصل الاجتماعي.
- خط الحد: $\le 140$ سطراً.

### المهمة 5: محاكي الويب الحقيقي عبر IFrame المتقدم (`PhoneWebviewIframe.tsx`)
- إطار iframe متطور مع تحكم بنسبة التكبير/التصغير (Scale Zoom) وتدرج التحميل (Loading Skeleton).
- دعم تبديل الوضع بنقرة واحدة داخل مجسم الهاتف بين (Simulator / Webview).
- خط الحد: $\le 110$ سطراً.

### المهمة 6: تحديث شريط التحكم في المعاينة (`MobilePreview.tsx` & `PhoneMockup.tsx`)
- أزرار سريعة لاختيار لون الهاتف (تيتانيوم طبيعي / أسود / ذهبي).
- زر مسح الباركود السريع بكاميرا الهاتف الواقعي (QR Code Modal).
- زر التبديل بين محاكي المكونات ومتصفح الويب المباشر.
- خط الحد: $\le 160$ سطراً.

### المهمة 7: الاختبارات والتحقق الشامل (Verification)
- اختبارات وحدة في `tests/unit/interactive-phone-preview.test.tsx`.
- فحص الأنواع `npx tsc --noEmit` (0 أخطاء).
- فحص Vitest الشامل واختبار E2E المباشر.
