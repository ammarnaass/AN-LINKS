# وثيقة مفهوم EGM: نظام المعاينة الحية والتفاعلية فائقة الواقعية للهاتف الذكي (Ultra-Realistic Interactive Phone Live Preview RFC)

* **المشروع:** AN LINKS
* **المؤلف:** Antigravity AI & Ammar
* **الحالة:** معتمد للتنفيذ (Approved for Implementation)
* **التاريخ:** 2026-11-24
* **المسار:** `docs/egm/interactive-phone-live-preview-concepts-brief.md`

## 1. بيان المشكلة والدافع (Problem Statement & Motivation)

في النظام الحالي، المعاينة المصغرة على اليمين في لوحة التحكم (`/dashboard`) عبارة عن واجهة ثابتة نسبياً:
1. **غياب التفاعلية الحقيقية:** الروابط تظهر كعناصر `div` غير قابلة للنقر، ولا يمكن للمستخدم اختبار النقر عليها، أو اختبار فتح الروابط الخارجية، أو تجربة المظهر الحركي (Hover/Active press).
2. **غياب شريط المتصفح المحاكي:** لا يوجد شريط عنوان هاتف ذكي (Safari/Chrome Address Bar) يعكس رابط الصفحة الفعلي `anlinks.dev/{username}` مع أيقونة الأمان المشفرة (SSL Padlock) وزر إعادة التحميل الفوري.
3. **جمود الجزيرة التفاعلية وشريط الحالة:** الوقت ثابت على "9:41" بشكل مصطنع، والجزيرة التفاعلية (Dynamic Island) غير متفاعلة مع النقرات أو الأحداث.
4. **عدم وجود خيار المعاينة المزدوجة (Dual Preview Modes):**
   - **النمط السريع التفاعلي (Interactive Simulator Mode):** استجابة فائقة السرعة مع نقرات تفاعلية وتأثيرات Haptic ولمسات حركية.
   - **نمط الويب الحقيقي (True Webview Mode):** تشغيل الصفحة الحقيقية داخل إطار Iframe منعزل مع دعم التمرير الكامل والـ SSR المطابق بنسبة 100% لما يراه الزائر الفعلي في متصفح هاتفه.

## 2. الرؤية الهندسية ومكونات النظام المبتكر (System Architecture)

### أ) مجسم الهاتف الواقعي (Ultra-Realistic Phone Chassis v2)
* **هيكل التيتانيوم الطبيعي (Titanium Chassis):**
  - تدرجات معدنية مع انعكاسات ضوئية دقيقة (Specular Highlights).
  - أزرار جانبية ثلاثية الأبعاد (زر التشغيل، أزرار الصوت، وزر الإجراء Action Button).
  - شبكة مكبر الصوت السفلية ومؤشر الرجوع للشاشة الرئيسية (Home Indicator).
  - زوايا دقيقة بنصف قطر مطابق لهواتف الفئة الرائدة (Corner Radius Curvature).

### ب) شريط الحالة والجزيرة التفاعلية الذكية (Interactive Dynamic Island & Status Bar)
* **ساعة رقمية حية (Live Realistic Time):** تعرض التوقيت المحلي الفعلي للمستخدم بصيغة 12/24 ساعة.
* **أيقونات الاتصال الحقيقية:** قوة إشارة شبكة 5G و Wi-Fi ونسبة البطارية الواقعية.
* **الجزيرة التفاعلية الحية (Interactive Pill):** إمكانية النقر عليها لتوسيعها وعرض بطاقة مصغرة تشير إلى حالة الصفحة (مثلاً: `AN LINKS Live • 100% Online`).

### ج) شريط متصفح الهاتف المحمول (Mobile Safari/Chrome URL Bar)
* شريط علوي/سفلي مدمج في الهاتف يحاكي متصفحات الهواتف الحديثة:
  - عرض الدومين: `🔒 anlinks.dev/{username}`
  - زر إعادة التحميل (Reload Preview) لتحديث فوري بدون إعادة تحميل صفحة الداشبورد.
  - زر نسخ الرابط السريع (Copy Link) مع تنبيه Toast أنيق داخل الهاتف.
  - زر فحص كود الاستجابة السريعة (QR Code Modal).

### د) الروابط التفاعلية وتجربة الاستخدام (Interactive Touch Links)
* عند النقر على أي رابط داخل المعاينة:
  - يظهر تأثير الضغط والتموج الفعلي (Micro-scale 0.98 + Ripple effect).
  - نافذة منبثقة تفاعلية ذكية (Simulated In-App Browser Preview أو خيار الانتقال المباشر للرابط الخارجي) تسمح للمستخدم بالتأكد من صحة الرابط.
  - أيقونات التواصل الاجتماعي تفتح أو تعرض الرابط الفعلي بدقة.

### هـ) مبدّل الأنماط والمقاسات (Preview Viewport Controls)
* **أزرار التحكم العلوية في المعاينة:**
  1. تبديل الوضع بين: **«محاكي سريع (Simulator)»** و **«متصفح حقيقي (Webview IFrame)»**.
  2. تبديل لون هيكل الهاتف: **Natural Titanium (رمادي تيتانيوم)**، **Deep Obsidian (أسود فلكي)**، **Desert Gold (ذهبي صحراوي)**.
  3. زر تكبير/تصغير (Zoom / Fit): 100% أو 90% أو ملء الشاشة.
  4. زر QR Code المباشر لعرض باركود كبير يتيح للمستخدم مسحه بكاميرا هاتفه الحقيقي لمعاينة الصفحة فوراً على جهازه الفعلي.

## 3. مصفوفة الجودة ومعايير EGM (Quality Invariants)

1. **معيارية الملفات:** الحفاظ على تقسيم المكونات بحيث لا يتجاوز أي ملف 250 سطراً (`feature-modular-structure`).
2. **الأداء وسلاسة العرض:** معدل إطارات 60FPS وتحديث فوري لأي تغيير لوني أو نصي في أقل من 16 مللي ثانية.
3. **تغطية الاختبارات:** اختبارات وحدة شاملة لمكونات الهاتف التفاعلي بنسبة نجاح 100% في Vitest.
4. **أمان الإطارات (Iframe Security):** حماية الـ iframe عبر `sandbox` ملائم لمنع التعارضات مع الجلسات الخارجية.
